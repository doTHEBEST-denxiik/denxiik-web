Зроблено з турботою

Читати не треба

Усі завдання озвучено, тож навіть той, хто ще не читає, може грати сам.

Без «game over»

Без таймерів і рахунку, який треба побити. Помилка — це просто ще одна спроба.

Безпечно за задумом

Без акаунтів, чату й особистих даних. Налаштування захищені батьківським контролем.

Дві мови

Англійська та іспанська, з голосом обома. Мова залежить від пристрою.

Для батьків

Без акаунтів, без чату і без збору персональних даних. Прогрес зберігається лише на пристрої, налаштування захищені батьківським контролем, покупок у застосунку немає. Ігри безкоштовні, з невеликою кількістю безпечних для дітей неперсоналізованих реклам — ніколи під час гри.
